機能

利用状況をひと目で把握

DeepSeek の Web コンソールと同じリクエストのみを送り、それを読みやすいダッシュボードにまとめます。

ウォレット残高

有償残高とボーナス残高を分けて表示。設定したしきい値を下回るとアイコンが赤くなります。

本日の利用額

本日の利用額とトークン数。「今日」は別途取得するため、日付が変わるまで数値が正確です。

API キー別の集計

どのキーが一番高くついているかが分かります。アイコンとグラフは 1 つのキーまたは任意のキーの組み合わせに絞り込めます。

30 日間のグラフ

選択した期間の日別バー。リストのキーをクリックすると、バーが色分けされた積み上げセグメントと凡例に切り替わります。

任意の指標をアイコンに

本日の利用額、期間の利用額、残高、トークン数 — ツールバーアイコンに何を表示するかは自由に選べます。

自動更新

データは設定した間隔でバックグラウンド更新されます（既定は 1 分ごと）。無効にもでき、手動更新ボタンは常に使えます。

別途の登録も API キーも不要。ブラウザですでに開いているセッションをそのまま利用します。

01

拡張機能をインストール

Chrome ウェブストアからワンクリック。Chrome 116 以降が必要です。

02

platform.deepseek.com を開く

03

スクリーンショット

実際の画面

ダークな UI、密度の高いグリッド、余計なボタンは一切なし。

既定でプライベート

拡張機能が通信するのは platform.deepseek.com のみで、DeepSeek の Web コンソールと同じ読み取り専用リクエストを送るだけです。API キーもパスワードも保存せず、ブラウザですでに開いているセッションを使います。データはお使いのコンピューター内だけに保存され、テレメトリー・アクセス解析・広告・第三者への提供は一切ありません。拡張機能を削除すればデータも消えます。

FAQ

よくある質問

DeepSeek の API キーは必要ですか？

いいえ。拡張機能は platform.deepseek.com でブラウザにログイン済みのセッションを利用します。API キーとパスワードは要求も保存もしません。

データがどこか別の場所へ送られることはありますか？

いいえ。リクエストは platform.deepseek.com のみに送られ、それ以外はローカルに留まります。アクセス解析・テレメトリー・広告はありません。

アイコンに「−」が表示される場合は？

DeepSeek の WAF トークンが期限切れです。platform.deepseek.com を一度開けばトークンが自動更新され、次回の更新時に拡張機能が取得します。拡張機能が自分でタブを開くことはありません。

アイコンに「!」や認証エラーが表示される

セッションが見つからないか期限切れです。プラットフォームにログインしてから、拡張機能の設定で「セッションを再検出」を押してください。

「今日」の数値はどの程度正確ですか？

プラットフォームの日別データには当日分が含まれないため、拡張機能は「今日」を時間別データから取得してグラフに別途加算します。

Firefox 版はありますか？

現在は Chrome と Chromium 系ブラウザ（Edge、Brave、Arc）のみです。Chrome 116 以降が必要です。
