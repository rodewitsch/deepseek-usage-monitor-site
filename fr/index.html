Fonctions

Tout sur vos dépenses en un coup d'œil

L'extension ne rejoue que les requêtes faites par la console web DeepSeek et les transforme en un tableau de bord lisible.

Solde du portefeuille

Solde payant et bonus séparés. Dès que le solde passe sous votre seuil, l'icône devient rouge.

Dépenses du jour

Dépenses et nombre de jetons du jour. « Aujourd'hui » est récupéré à part pour que le chiffre reste juste jusqu'au changement de jour.

Suivi par clé API

On voit quelle clé coûte le plus. L'icône et le graphique peuvent être limités à une clé ou à une sélection de clés.

Graphique sur 30 jours

Barres par jour sur la période choisie. Cliquez sur des clés dans la liste : les barres deviennent des segments empilés avec une légende de couleurs.

Icône selon votre métrique

Dépenses du jour, de la période, solde ou jetons : c'est vous qui décidez ce que montre l'icône de la barre.

Actualisation automatique

Les données se mettent à jour en arrière-plan selon un planning (toutes les minutes par défaut) ou pas du tout. Un bouton d'actualisation manuelle est toujours disponible.

Comment ça marche

Trois étapes jusqu'au premier graphique

Pas d'inscription séparée ni de clé API : l'extension réutilise la session déjà ouverte dans le navigateur.

01

Installez l'extension

En un clic depuis le Chrome Web Store. Chrome 116 ou plus récent requis.

02

Connectez-vous : la session est récupérée automatiquement.

Confidentielle par défaut

L'extension ne communique qu'avec platform.deepseek.com et effectue les mêmes requêtes en lecture seule que la console web DeepSeek. Aucune clé API ni mot de passe n'est stocké : elle réutilise la session déjà ouverte dans le navigateur. Toutes les données restent sur votre ordinateur : pas de télémétrie, d'analyse, de publicité ni de partage avec des tiers. Désinstallez l'extension et les données disparaissent.

FAQ

Questions fréquentes

Faut-il une clé API DeepSeek ?

Non. L'extension utilise la session déjà ouverte dans le navigateur sur platform.deepseek.com. Ni clé API ni mot de passe ne sont demandés ou stockés.

L'extension envoie-t-elle mes données ailleurs ?

Non. Les requêtes vont uniquement vers platform.deepseek.com, le reste reste en local. Pas d'analyse, de télémétrie ni de publicité.

L'icône affiche « − », que faire ?

Le jeton WAF de DeepSeek a expiré. Ouvrez une fois platform.deepseek.com : le jeton se renouvelle et l'extension le récupère à l'actualisation suivante. Elle n'ouvre jamais d'onglets d'elle-même.

L'icône affiche « ! » ou une erreur d'autorisation

La session est introuvable ou expirée. Connectez-vous à la plateforme, puis cliquez sur « Redétecter la session » dans les réglages de l'extension.

Quelle est la fiabilité du chiffre « aujourd'hui » ?

La série journalière de la plateforme n'inclut pas le jour en cours avant sa fin ; l'extension prend donc « aujourd'hui » dans la série horaire et l'ajoute séparément au graphique.

Y a-t-il une version Firefox ?

Pour l'instant uniquement Chrome et les navigateurs basés sur Chromium (Edge, Brave, Arc) — Chrome 116+ requis.
