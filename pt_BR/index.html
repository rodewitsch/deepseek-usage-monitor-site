Recursos

Tudo sobre seus gastos de relance

A extensão repete apenas as requisições que o próprio console web do DeepSeek faz e transforma isso em um painel legível.

Saldo da carteira

Saldo pago e bônus separados. Quando o saldo cai abaixo do seu limite, o ícone fica vermelho.

Gasto de hoje

Gasto e quantidade de tokens do dia. “Hoje” é buscado separadamente para o número ficar certo até a virada do dia.

Controle por chave de API

Dá para ver qual chave custa mais caro. O ícone e o gráfico podem ser limitados a uma chave ou a qualquer seleção.

Gráfico de 30 dias

Barras por dia do período escolhido. Clique nas chaves da lista e as barras viram segmentos empilhados com legenda de cores.

Ícone com a sua métrica

Gasto de hoje, gasto do período, saldo ou tokens — você decide o que o ícone da barra mostra.

Atualização automática

Os dados são atualizados em segundo plano conforme um intervalo (a cada minuto por padrão) ou nem isso. O botão de atualizar manualmente está sempre lá.

Como funciona

Três passos até o primeiro gráfico

Sem cadastro separado e sem chave de API — a extensão usa a sessão que já está aberta no navegador.

01

Instale a extensão

Um clique na Chrome Web Store. Requer Chrome 116 ou mais recente.

02

Abra platform.deepseek.com

Entre na conta — a sessão é detectada automaticamente.

03

Clique no ícone

A primeira atualização acontece sozinha. Depois os dados se atualizam em segundo plano.

Privada por padrão

A extensão fala apenas com platform.deepseek.com e faz as mesmas requisições somente de leitura que o console web do DeepSeek. Nenhuma chave de API ou senha é armazenada — ela usa a sessão já aberta no navegador. Todos os dados ficam no seu computador: sem telemetria, analytics, anúncios ou envio a terceiros. Removeu a extensão? Os dados somem com ela.

3 requisições

Somente os endpoints do console necessários para saldo e gastos.

0 domínios externos

Sem servidores de terceiros, CDNs ou relatórios de erro.

Armazenamento local

Configurações e números em cache ficam em chrome.storage.local.

FAQ

Perguntas frequentes

Preciso de uma chave de API do DeepSeek?

Não. A extensão usa a sessão que já está aberta no navegador em platform.deepseek.com. Nem a chave de API nem a senha são pedidas ou armazenadas.

A extensão envia meus dados para algum outro lugar?

Não. As requisições vão só para platform.deepseek.com; o resto fica local. Sem analytics, telemetria ou anúncios.

O ícone mostra “−”, o que fazer?

O token WAF do DeepSeek expirou. Abra platform.deepseek.com uma vez — o token é renovado e a extensão o pega na próxima atualização. Ela nunca abre abas sozinha.

O ícone mostra “!” ou erro de autorização

A sessão não foi encontrada ou expirou. Entre na plataforma e pressione “Redetectar sessão” nas configurações da extensão.

Quão precisa é a cifra “hoje”?

A série diária da plataforma não inclui o dia atual até ele acabar, então a extensão pega “hoje” da série horária e soma separadamente no gráfico.

Existe versão para Firefox?

Por enquanto apenas Chrome e navegadores baseados em Chromium (Edge, Brave, Arc) — requer Chrome 116+.
