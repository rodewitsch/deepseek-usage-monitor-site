Tangkapan layar

Tampilannya

Privat secara default

Ekstensi hanya menghubungi platform.deepseek.com dan melakukan permintaan baca-saja yang sama dengan konsol web DeepSeek. Tidak ada API key atau kata sandi yang disimpan — ekstensi memakai sesi yang sudah terbuka di browser. Semua data hanya ada di komputer Anda: tanpa telemetri, analitik, iklan, dan tanpa dibagikan ke pihak ketiga. Hapus ekstensinya dan data ikut hilang.

FAQ

Pertanyaan umum

Apakah perlu API key DeepSeek?

Tidak. Ekstensi memakai sesi yang sudah terbuka di browser di platform.deepseek.com. API key dan kata sandi tidak diminta maupun disimpan.

Apakah ekstensi mengirim data saya ke tempat lain?

Tidak. Permintaan hanya ke platform.deepseek.com, sisanya tetap lokal. Tanpa analitik, telemetri, dan iklan.

Ikon menampilkan “−”, apa yang harus dilakukan?

Token WAF DeepSeek sudah kedaluwarsa. Buka platform.deepseek.com sekali — token diperbarui sendiri dan ekstensi mengambilnya pada penyegaran berikutnya. Ekstensi tidak pernah membuka tab sendiri.

Ikon menampilkan “!” atau error otorisasi

Sesi tidak ditemukan atau sudah kedaluwarsa. Masuk ke platform, lalu tekan “Deteksi ulang sesi” di pengaturan ekstensi.

Seberapa akurat angka “hari ini”?

Rangkaian harian platform belum memuat hari berjalan sampai hari itu berakhir, jadi ekstensi mengambil “hari ini” dari rangkaian per jam dan menambahkannya terpisah ke grafik.

Apakah ada versi Firefox?

Saat ini hanya Chrome dan browser berbasis Chromium (Edge, Brave, Arc) — butuh Chrome 116+.
